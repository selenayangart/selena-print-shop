# Demo assets

## Artwork

`images/art/` contains only two neutral gray SVG placeholders. No Selena Yang paintings, scans, thumbnails, or private catalog documents are included. Replace the placeholder paths in `data/works.js` with images you have permission to publish.

The placeholders are sample interface assets, not print-ready artwork. See `RIGHTS.md`.

## Room environments

`images/rooms/` contains the existing demo room photographs/renderings and scale figure used by the portfolio's viewing-room feature. They are included to reproduce that feature, not under a separate permissive asset license. No original room source files are included. Review ownership and permissions before distributing these assets under a different license.

## Fonts and icons

The standalone demo uses system fonts, so it does not redistribute the site's font files. Existing interface SVG icons remain embedded in the extracted source.
